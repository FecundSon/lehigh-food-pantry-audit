# Lehigh County, PA — Food Pantry Listing Audit

**Checked: 2026-10-24. Status: published here first for statewide PA 211 and the
pantries to respond to. Nothing in this audit has been sent to statewide PA 211,
Second Harvest, or any pantry as a direct message.**

## What this is
A small, dated audit of 20 food pantry listings for Lehigh County, PA,
checked against the pantries' own websites and other public listings.
It is a curation audit, not a replacement directory: it does not claim
to be a current list of open pantries, and it should not be used as one
without checking with the pantry or PA 211 first.

## Method and limits — please read before using this
- Public web search and page-text fetch only, 2026-10-24. No pantry,
  PA 211, or anyone else was contacted for this audit.
- A pantry's own website is treated as authoritative over third-party
  directories. Where a pantry's own site did not state an address or
  hours, that item is marked UNVERIFIED in the full report — it is a gap
  in public web evidence, not a finding, and must not be published as fact.
- **No pantry is called defunct or closed in this audit.** A failed or
  missing page is reported as unverified, never as closure.
- A live website does not by itself prove a pantry is currently operating.
- Hours from a church/office page are not pantry hours, and are flagged
  as such wherever that confusion was possible.
- This audit was prepared with AI assistance. Corrections, challenges,
  and updates from statewide PA 211 or the pantries themselves are welcome —
  that is the point of publishing it here first.
